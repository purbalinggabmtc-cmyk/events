# 1. Project Overview

BOLD AFTER DARK adalah aplikasi event ticketing sederhana berbasis:

- Frontend: GitHub Pages (HTML, CSS, JavaScript)
- Backend: Google Apps Script Web App
- Database: Google Spreadsheet
- QR Access: QR Code berdasarkan ID peserta

Tujuan sistem:

1. Registrasi peserta
2. Generate ID unik peserta
3. Dashboard tiket digital
4. Login peserta
5. Merchandise purchase
6. Lucky draw number generation
7. Check-in event
